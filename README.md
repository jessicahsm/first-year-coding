This repository will contain the practice code and small projects I write as I learn programming concepts during my first year.

## How I think GitHub will be useful in college
I think GitHub will be useful in college as a place to keep all of my code backed up and organized, so I can work on it from any computer and never lose progress. It will also let me track changes as I learn, which means I can look back at older versions and see how much I’ve improved. Beyond my own work, I expect to use it for group projects, since it makes it easy for teammates to collaborate on the same code. Over time, I hope my GitHub profile becomes a portfolio I can show when applying for internships.
